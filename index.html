1단계. 줄거리 쓰기

줄거리는 직접 작성합니다. 아래 칸에 이야기를 쓰거나 붙여넣고, 책 분량(페이지 수·페이지당 문장 수)을 정하세요. 분량은 2단계에서 장면(배경)을 몇 개 뽑을지, 3단계에서 원고를 어떻게 나눌지의 기준이 됩니다. 컨셉트·대상·주제는 선택 항목입니다.

초안을 받은 뒤에도 자유롭게 고칠 수 있습니다.

2단계. 에셋 참조 프롬프트 만들기 핵심

동화책 그림에 반복해서 쓰일 에셋 세 종류의 참조 이미지 프롬프트를 만듭니다. 캐릭터는 여러 번 등장하는 주요 캐릭터만(일관성 유지), 장면은 이야기에 필요한 배경을 개수 제한 없이 모두, 도구는 중요한 물건·소품을 뽑습니다.

사용 팁 각 에셋 프롬프트로 참조 이미지를 1장씩 먼저 만들어 두세요. 캐릭터는 앞·옆·뒤 전신과 표정 여러 개가 한 장에 담긴 캐릭터 시트로 나오므로, 장면에서 뒷모습이나 다른 표정이 필요할 때도 같은 시트 한 장을 첨부하면 됩니다. 4단계 장면 프롬프트를 쓸 때 그 페이지에 쓰이는 캐릭터·장면·도구 참조 이미지를 함께 첨부하면, 캐릭터뿐 아니라 배경과 물건의 일관성도 유지됩니다.
에셋 카드
종류별 색: 캐릭터장면도구
아래 원본 표를 직접 고치면 카드도 함께 바뀌고, 다음 단계에도 고친 내용이 사용됩니다. (열 순서: 종류 | 에셋 이름 | 설명 | 참조 이미지 프롬프트)

4단계. 장면 프롬프트와 사용 에셋

2단계 에셋 표와 3단계 원고를 자동으로 사용합니다. 페이지마다 전체 장면 프롬프트와 그 그림에 들어가는 캐릭터·장면·도구 에셋을 색으로 표시합니다. 이미지 생성 AI에 프롬프트를 넣을 때 표시된 에셋의 참조 이미지를 함께 첨부하세요.

장면별 최종 이미지 프롬프트 카드
칩을 누르면 그 에셋의 참조 프롬프트가 복사됩니다 · 캐릭터장면도구 2단계 표에 없음
아래 원본 표를 직접 고치면 카드도 함께 바뀝니다. 카드의 복사 버튼을 누르면 장면 프롬프트 + 첨부할 참조 이미지 안내 + 화풍·크기 태그가 함께 복사됩니다. (열 순서: 페이지 | 사용 에셋 | 장면 프롬프트)

1~4단계의 입력과 결과를 JSON 파일로 저장해 두면, 다른 컴퓨터나 브라우저에서 불러와 이어서 작업할 수 있습니다. (API 키는 저장되지 않습니다)

모든 입력과 결과는 이 컴퓨터의 브라우저에 자동 저장되어, 새로고침해도 유지됩니다.
